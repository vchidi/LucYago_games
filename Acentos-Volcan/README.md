# Acentos-Volcan

Juego HTML para practicar acentuación en español.

## Subir a GitHub

Copiar esta carpeta dentro de:

LucYago_Games/Acentos-Volcan

## Archivo principal

index.html

## Integración con menú principal

Desde el menú principal enlazar a:

Acentos-Volcan/index.html

## Características

- Optimizado para iPad
- Volcán dinámico
- Banco editable de palabras
- Modo revisión de errores
- Preparado para otros idiomas
